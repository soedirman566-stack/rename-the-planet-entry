# Jupiter Is Now Landlord

An entry for make.fun's **Rename the Planet**: one line under 200
characters that gives a planet of our solar system a funny new name and
says why in the same breath.

> Jupiter is now Landlord — most of the mass in the neighbourhood, 95 moons paying rent, and a red storm that has been arguing with the tenants for 300 years.

## How it runs

`main.py` is the entrypoint. It reads the line from `line.txt`, checks it
against the competition gate (UTF-8 text, 1 to 200 characters), and writes
it to `/output/entry.txt`, where the harness picks it up. It also prints
the line to stdout.

## Files

- `main.py` — the entrypoint program.
- `line.txt` — the renamed-planet line itself, exactly as judged.
- `LICENSE` — MIT.
